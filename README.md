# X-O Game

## Description
The X-O Game (also known as Tic-Tac-Toe) is a classic two-player game where players take turns marking a space in a 3x3 grid. The goal is to be the first player to get three of their marks in a row—horizontally, vertically, or diagonally.

## Features
- Simple user interface for input.
- Players can choose their marks (X or O).
- Checks for win conditions after each move.
- Displays the game board after each turn.
- Notifies players when the game ends (win or draw).

## Requirements
- C Compiler (e.g., GCC)
- Basic knowledge of command-line operations.

## Running the Program

1. Clone the repository:
        In bash
    git clone https://github.com/PopaaaAlex/X-0.git

2.Navigate into the project directory:
    cd X-0

3. Use the Makefile to compile the program:
    make

4. Run the program:
    ./X-0  or   make run


## Game Instructions
    -Players take turns entering their move coordinates (row and column) to place their mark on the board.
    -The first player to align three of their marks wins the game.
    -If all spaces are filled without a winner, the game ends in a draw.
